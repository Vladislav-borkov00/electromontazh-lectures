Публикация и развертывание на GitHub

Этот проект спроектирован так, чтобы его можно было в один клик опубликовать на GitHub Pages без серверов и сложной сборки.

Инструкция по шагам:

  1. Создайте новый публичный репозиторий на GitHub (например, electro-lectures).
  2. Скачайте файл с вашими лекциями через кнопку Скачать JSON в боковой панели.
  3. Поместите скачанный файл как lectures.json рядом с главным index.html.
  4. Загрузите код на GitHub в ветку main.
  5. Перейдите в настройки репозитория: Settings -> Pages, выберите ветку main и нажмите Save.
Рекомендуемая структура файлов: 
electro-lectures/
├── index.html         # Основное приложение
├── lectures.json      # Загружаемый файл с лекциями
└── README.md          # Описание вашего курса
